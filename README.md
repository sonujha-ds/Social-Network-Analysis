
Social Network Connection and Recommendation Analysis

Project Description

This project is a Python-based Social Network Analysis System. It represents users as vertices (nodes) and their connections as edges in a graph.

The project uses BFS and DFS algorithms to explore connections and find the shortest path between users.

Features

1. Add User
2. Add Connection
3. Display Network
4. Find Mutual Friends
5. Find Shortest Path using BFS
6. Explore Network using DFS

Technologies Used

- Python
- Graph Data Structure
- Dictionary
- List
- BFS Algorithm
- DFS Algorithm

Project Objectives

- Understand graph data structures.
- Explore connections between users.
- Find mutual friends.
- Find the shortest path between two users.
- Implement BFS and DFS algorithms.

How to Run the Project

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python social_network.py

5. Select an option from the main menu.

Algorithms Used

BFS (Breadth-First Search): Finds the shortest connection path in an unweighted graph.

DFS (Depth-First Search): Explores the network by visiting connected users deeply before backtracking.
